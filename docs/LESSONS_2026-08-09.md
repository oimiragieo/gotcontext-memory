# Lessons learned — gotcontext-memory (2026-08-09)

Retain across sessions. Agents: read with `AGENTS.md` + [`docs/SKILLS.md`](./SKILLS.md)
(`gotcontext-memory-hitl-honesty`, `gotcontext-memory-streaming-digests`,
`gotcontext-memory-claim-lifecycle`).

## L1 — A green test that cannot fail is a lie
**Receipt:** Symlink-escape test called `symlink` without importing it; `catch` treated `ReferenceError` as “Windows skip.” Always green, never proved containment.  
**Rule:** Skip only on named errno (EPERM/EACCES). Never catch `ReferenceError`. Bidirectional control required.

## L2 — Detect ≠ enforce
**Receipt:** Doctor printed `index_caps` lines/bytes but always `status: pass`.  
**Rule:** If doctor claims a cap, fail when over. Share the same counter as commit (`countIndexLines`).

## L3 — One lock identity per logical resource
**Receipt:** Create locked `locks/<hash>`; update/delete locked the real file → create↔delete race.  
**Rule:** Always lock the stable stub key for a relative path. Never switch identity when the file appears.

## L4 — Shared indexes must be rebuilt under the lock
**Receipt:** Accept computed `MEMORY.md` before locks, then CAS’d stale bytes over a concurrent winner.  
**Rule:** Mutate target, then regenerate index from live tree while still holding locks. Concurrent accept test required (sequential cannot catch it).

## L5 — HITL honesty dies if an agent can commit
**Receipt:** MCP `memory_commit` called `commitCanonical` while docs said “only human accept.”  
**Rule:** Default-off commit (`mcp.allowCommit: false`). Keep `memory_propose` → `review accept`. Opt-in is a conscious non-HITL mode — document it.

## L6 — Prior PASS audits are hypotheses
**Receipt:** Codex round-5 said no HIGH blockers; Wave-1 reopened CRITICAL lock/index + HIGH MCP/HITL.  
**Rule:** Re-audit with falsification + concurrent oracles after big claims. Don’t treat last PASS as gospel.

## L7 — Pipeline alive ≠ useful dream
**Receipt:** PC transcript_dream hourly success; all overnight proposals were “respond with exactly: pong”; 0 accepts.  
**Rule:** Report selection + staged content quality + accepts, not only “run succeeded.”

## L8 — Sequential oracles miss concurrency bugs
**Receipt:** Thinktank critic correctly REJECT’d a sequential “two accepts” red arm — live tree walk already saw both.  
**Rule:** Overlap writers (two processes) for lock/index races.

## L9 — Thinktank smoke ≠ thinktank workload
**Receipt:** `tt_smoke` 8/8 green; `tt_quick` PROVIDER_FAILURE / STRUCTURED_INVALID.  
**Rule:** Keep 3-lens Claude Workflow fallback; don’t block shipping on flaky council infra when seats smoke OK.

## L10 — Package dream ≠ omega dream
**Receipt:** gotcontext = regex preferences + markdown proposals; PC omega = LLM reviewer + SQLite proposals + manifests.  
**Rule:** Never claim parity with `memory_dream` or full `transcript_dream`. HONESTY.md is load-bearing.

## L11 — Preference regex is a poison hose
**Receipt:** Bare `always`/`prefer` matched health-check prose.  
**Rule:** Anchor on `please remember` / `from now on`; deny pong/ping/health spans; test negative FPs.

## L12 — Empty object is not an empty list
**Receipt:** `regenerateIndex(..., { deletes: {} })` → “object is not iterable.”  
**Rule:** Pass `deletes: []`. Type the overlay; don’t invent empty-object arrays.

## L13 — Exa unavailability must be labeled
**Receipt:** No Exa MCP / no `EXA_API_KEY` this session; used WebSearch.  
**Rule:** Say what freshness path ran. Don’t invent “Exa said…”.

## L14 — Informational config flags confuse operators
**Receipt:** `dream.enabled` was display-only while CLI always dreamed; then wired to refuse without `--force`.  
**Rule:** Either enforce the flag or stop doctor/docs from implying it gates behavior.

## L15 — Real corpus scale is a hard requirement, not an optimisation
**Receipt:** 9.6 GB / 11,683 Claude transcripts; one 2.3 GB file — `readFile` throws >2 GiB. Accumulating full `Transcript[]` cannot work.  
**Rule:** Stream into bounded digests (~1 KB). Separate **truncated** from **malformed**. Prove failure on a real oversized file before claiming “works.”

## L16 — Rejected (and accepted) claims must not resurrect
**Receipt:** Nothing read `proposals/rejected/`; deterministic regex re-emitted identical proposals forever; re-accept overwrote human-edited memory with regex body.  
**Rule:** Rejected → suppress by stable `claimKey` independent of `base_hash`. Accepted prefs → skip when `targetPath` already exists in store hashes (so human edits survive). Red tests for both arms.

## L17 — Unbounded prevalence is true and useless
**Receipt:** 386 proposals with denominators like `16/17263`.  
**Rule:** Window with `--max-sessions` (default 400). Report k/n against that window only. Sort `maxProposals` by evidence strength, never by hash id.

## L18 — Closing OOM can regress a harness path
**Receipt:** Digest path enumerates `*.jsonl` only → Cursor `.vscdb` dropped from dream.  
**Rule:** Document in HONESTY immediately; track as pre-1.0.0 must-fix (BL-DRM-016).

## L19 — Don’t commit tool session caches
**Receipt:** `src/.tensor-grep/sessions/*` landed in `2676a6c` (~900 lines).  
**Rule:** gitignore `.tensor-grep/`; never stage under `src/`. Strip before merge.

## L20 — Dirty trees swallow other agents’ work
**Receipt:** One `git add` on a dirty tree co-mingled deep-dive remediation with digest/prevalence (~890 pre-existing insertions attributed to the digest author).  
**Rule:** `git add <only-my-paths>`; verify with `git diff --cached --name-status` vs `git diff --name-only`. Untangle before merge if another agent owns the rest.

## L21 — Capability jumps need a skill/docs lane, not just code
**Receipt:** Digests/prevalence shipped on main while `dream.md`, AGENTS, and skills still described the old Transcript[] dream path until a four-lane retention workflow.  
**Rule:** After a method change, fan out docs + skill audit + new skills + entrypoints (`docs/WORKFLOWS.md`). Skills must cite live `file:line` mechanisms (accepted ≠ rejected suppression).
